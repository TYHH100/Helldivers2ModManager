# 新前端人工验收清单

## 验收环境

- 只运行 `next/frontend/src/Helldivers2ModManager.Frontend.Host`。
- 独立数据目录：`%LOCALAPPDATA%\Helldivers2ModManagerNext`。
- 验收期间不要把任何数据手工迁移到旧程序目录。

## 1. 启动与全局界面

| 检查项 | 通过标准 |
|---|---|
| 冷启动 | Host 正常启动，无空白页、无异常弹窗。 |
| 顶部模块 | 模组库、部署、工具、分析、系统均可切换。 |
| 子导航 | 当前模块只显示自己的子页面，页面切换有明显过渡。 |
| 顶部快捷区 | 导入、部署、任务、搜索可见且可操作。 |
| 中英文切换 | 设置切到 `en-US` 后重启或重新进入页面时标题和描述不丢失关键文本。 |
| 键盘操作 | Tab 可聚焦按钮/输入框，焦点样式可见。 |
| 高对比 | 正文、复选框标签、下拉项在深色主题下清晰可读。 |

## 2. 模组库与选项部署

| 检查项 | 操作与通过标准 |
|---|---|
| 扫描模组库 | 已存在的 Mod 显示名称、描述、版本；无清单的目录进入问题列表而不是崩溃。 |
| 压缩包导入 | 选择 zip/7z/rar/tar 后显示进度；完成后列表刷新。 |
| 创建 Mod | 选择源目录、填写名称，可选 V1/Legacy、添加选项；创建后能在模组库看到。 |
| 编辑启用状态 | 勾选单个 Mod 的启用开关后立即保存并触发部署。 |
| 批量启停 | 批量启用/禁用后点击“部署启用项”，游戏目录反映最终状态。 |
| V1 选项 | 打开“选项”：每个选项开关保存生效；有子选项时可选择子选项。 |
| Legacy 选项 | Legacy 变体以单选形式展示，只能选一个，保存后部署生效。 |
| 删除 Mod | 删除选中 Mod 时确认后走回收站；数据库状态不再保留该 Mod 的普通状态。 |
| 导出 Mod | 导出 zip 成功，源 Mod 目录保持不变。 |
| 搜索过滤 | 名称、描述、选项名命中当前搜索词。 |
| 自动打标签 | 开启自动打标签后加载库会创建后台任务；禁用时不会扫描。 |

## 3. 部署与后台任务

| 检查项 | 操作与通过标准 |
|---|---|
| 复制模式部署 | 设置为复制模式时，游戏 data 目录出现目标 patch 文件。 |
| 符号链接部署 | 明确开启符号链接且权限足够时验证链接；权限不足应失败并可恢复设置。 |
| 部署顺序 | 上移/下移只影响部署优先级，不覆盖用户排序以外的状态字段。 |
| 清理游戏 data | 确认后清理本管理器部署的 patch 族文件；非 patch 文件不动。 |
| 进度 UI | 部署期间能看到步骤/进度，UI 不假死。 |
| 取消任务 | 大批量任务取消后状态变为已取消，后续页面不继续假更新。 |
| 任务页 | 前台任务不出现在任务页，后台任务显示终态。 |

## 4. 工具链

| 检查项 | 操作与通过标准 |
|---|---|
| 运行时编辑 | 修改启用/子选项后保存并返回模组库；再次部署使用新状态。 |
| 清单编辑 | 修改名称、描述、图标、Include、子选项；Legacy 引入 V1 特性时应升级为 V1 并保留 GUID。 |
| 标签管理 | 新增、重命名颜色/名称、删除标签；删除标签后 Mod 内运行时标签同步移除。 |
| 自动配对 | 类型映射未设置为空；设置为已有标签后保存持久化；“新建标签”能创建类型标签且重复创建被阻止。 |
| Nexus 解析 | 无 API Key 给出提示；配置有效 Key 后 URL 解析出域与 Mod ID，并展示文件。 |
| Nexus 下载导入 | 下载进入独立临时目录，导入成功后临时压缩包被清理。 |
| 网络失败 | 断网或无效 Key 时错误显示在状态栏，不影响本地库。 |

## 5. 分析与修复

| 检查项 | 操作与通过标准 |
|---|---|
| 版本检查 | 空补丁 Mod 允许完成；含 Unit 补丁显示状态、参考版本、Unit 数。 |
| 冲突扫描 | 只统计启用 Mod；报告参与者、胜者、是否确定冲突。 |
| 护甲复用 | 只读取启用 Mod 和所选补丁；无法识别时不编造护甲名。 |
| 资源查看器 | TOC/GPU/纹理三页能打开；大 GPU 文件只用元数据和受限样本。 |
| 纹理预览 | 选纹理后有加载态；不可解码显示不可用；连续切换不会旧图回写。 |
| 模型预览 | 有几何体模型渲染非空网格；空模型给出空结果；切换模型后旧请求取消。 |
| 二分排查 | 至少两个启用 Mod 开始；每轮保存并部署一半候选；崩溃/正常能收敛；单模组验证可用。 |
| 二分还原 | 取消还原原始启用状态；结束确认嫌疑后在原始快照中禁用嫌疑。 |
| 修复计划 | 先生成计划再确认执行；不支持项标记跳过，不得修改文件。 |
| 修复执行 | 执行前二次确认；成功后显示元数据/Unit/伴生恢复计数，失败显示阻断原因。 |
| 护甲污染边界 | 不开启护甲污染功能；诊断中心仅做安全只读分析和显式修复入口。 |

## 6. 系统

| 检查项 | 操作与通过标准 |
|---|---|
| 默认路径 | 存储目录默认为 `%LOCALAPPDATA%\Helldivers2ModManagerNext\data`；临时目录不带重复 `data\data`。 |
| 游戏自动检测 | 点击自动检测后填充 Steam 安装的游戏根目录；找不到时给出手动设置提示。 |
| 目录浏览 | 游戏/存储/临时目录可通过浏览对话框选择。 |
| 保存设置 | 保存后重启 Host，路径、语言、行为开关、API Key 仍保留。 |
| 数据隔离 | 旧程序目录下的 `settings.json` 与旧数据库 mtime/大小不变。 |
| 日志初始化失败 | 临时阻断存储目录写权限或换成不可访问路径，错误必须可见且应用进入可退出状态。 |

## 7. 冻结门槛

1. 独立解决方案构建零警告。
2. 全部自动化测试通过。
3. 架构守卫确认前端不引用旧主程序层。
4. 上述检查逐项人工签署结论。
5. 未通过的缺陷先记录现象、页面、输入样例、期望结果；修复后回归相关整组检查。
